# Библия

Stable app: https://tig1ran2-web.github.io/bibliya/ (0.18.1)

New design preview: https://tig1ran2-web.github.io/bibliya/preview-v0190/ (0.19.0)

The preview separates reading, research and reading rooms. Room messages are local to the browser. The video meeting screen is explicitly a mockup: it does not access a camera or microphone, connect participants or make calls.

The publishing script preserves the stable build byte for byte from its SHA-256 manifest, applies a verified preview patch in a separate folder and uploads the complete static site. Runtime application files are served from GitHub Pages. Original Flutter source, deployment copies and source archives remain on the owner's E drive. Fonts and their SIL Open Font License notices are bundled.
