# Библия

Published static application 0.18.1 with local CanvasKit startup assets. Main source files and build archives remain on the owner's E drive. The workflow verifies unchanged assets against SHA-256, applies the locally built patch, and publishes the complete site to GitHub Pages. Readers download all app assets from GitHub Pages; the previous host is only used during this initial build to copy already-public unchanged assets.

Source attribution and licenses are preserved inside site assets. Personal notes and settings remain in each reader's browser. Private reading rooms are not implemented; the rooms screen is a local mockup.
